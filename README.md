# Esquie local workspace

An independently authored, local-first chief-of-staff workspace: tasks and conversations, an unsent draft studio, a durable worker, local documents, owner-entered accounts/outcomes, and an optional Windows tray host. It is not a full reproduction of the private reference; see the [feature-by-feature parity report](docs/parity-report.md).

> **Incomplete source baseline, not a release-ready desktop distribution.** The desktop npm audit summary reported **six moderate issues**; advisory/package details were unavailable. No complete policy-compliant fresh desktop installation or real installer validation has been established. Earlier desktop artifacts have unverified policy provenance and must not be reused, distributed or published. Source publication does not resolve these limits; additional connector and identity assessments are still in progress.

**Connections are disconnected by default.** Microsoft 365 adapters require a trustworthy, separately authorized host token provider; no sign-in provider is installed here. Copilot remains unavailable until an audited runtime and identity boundary exist. No tests access real accounts.

> **Queue/retry safeguards and remaining limits:** same-tab, same-origin queue submissions are serialized and bind the request ID to the original task/payload fingerprint. Accepted-but-refresh-failed and unknown results are distinguished; an uncertain attempt stays blocked until Activity review. If Activity proves the job absent, only an explicit same-ID retry with matching original inputs is allowed. This is not a cross-tab or cross-origin lock; inspect durable Activity before starting replacement work elsewhere. Demo failures are not retried through the generic queue: review Activity and approvals, then submit a separate request with fresh format selection and fake-only confirmation. No automatic replay is performed.

> **Unresolved historical Word read:** an earlier concurrent test observed a fail-closed HTTP 409 while reading an eligible local Word document. The original response body was not retained. Separate bounded investigations on supported Node 22 and the unsupported Node 27 alpha each passed 107/107 original-suite cases plus targeted repeated runs without reproducing it. Neither establishes the cause or a fix; recurrence remains unknown. Keep the existing integrity checks fail-closed and do not treat the observation as resolved. Use Node 22 for release validation.

Independently choose and enter a separate parent directory outside the original installation and every existing checkout before running it: the clone is created beneath the current directory, and the command does not prove that location is safe.
```powershell
& { $ErrorActionPreference = 'Stop'; $null = Get-Command git -ErrorAction Stop; $null = Get-Command npm.cmd -ErrorAction Stop; if ($env:LOCALAPPDATA -notmatch '^[A-Za-z]:\\' -or $env:LOCALAPPDATA.Substring(2) -match '[<>:"|?*\x00-\x1f]') { throw 'LOCALAPPDATA must be an absolute local-drive path.' }; $null = [System.IO.Path]::GetFullPath($env:LOCALAPPDATA); $workspace = Join-Path -Path $env:LOCALAPPDATA -ChildPath 'EsquieLocal\MyPrivateWorkspace' -ErrorAction Stop; if ($workspace -notmatch '^[A-Za-z]:\\') { throw 'The workspace must be an absolute local-drive path.' }; if (Test-Path -LiteralPath $workspace -ErrorAction Stop) { throw 'Choose a different new, empty workspace path.' }; $clone = Join-Path -Path (Get-Location).Path -ChildPath 'Esquie_copilot_desktop_app'; if (Test-Path -LiteralPath $clone -ErrorAction Stop) { throw 'Choose a directory without an existing clone destination.' }; git clone -- https://github.com/alanhkim/Esquie_copilot_desktop_app.git $clone; if ($LASTEXITCODE -ne 0) { throw 'git clone failed; not starting.' }; Set-Location -LiteralPath $clone -ErrorAction Stop; npm.cmd ci --no-audit --no-fund; if ($LASTEXITCODE -ne 0) { throw 'npm ci failed; not starting.' }; if (Test-Path -LiteralPath $workspace -ErrorAction Stop) { throw 'The workspace path now exists; choose a different new path.' }; Set-Item -LiteralPath Env:ESQUIE_DATA_DIR -Value $workspace -ErrorAction Stop; npm.cmd start; if ($LASTEXITCODE -ne 0) { throw 'npm start failed.' } }
```
